# Babaji Herbal

```
babaji-herbal/
├── frontend/             # React + Vite application
│   ├── src/
│   ├── .env
│   ├── package.json
│   └── vite.config.js
└── backend/              # Express API
    ├── app.js
    ├── server.js
    ├── .env
    └── package.json
```

## Run the frontend

```powershell
cd frontend
npm install
npm run dev
```

If PowerShell blocks `npm.ps1`, use `npm.cmd run dev` instead. This does not require changing the execution policy.

## Run the backend

```powershell
cd backend
npm install
npm run dev
```
